# Schedule Tasks
定时任务管理中心,提供任务创建、Cron表达式配置、执行历史和监控能力,支持定时触发编排或单个角色技能。

Layout Hierarchy:
- Header (Full-width):
  - Top Navigation Bar
- Content Container (Positioned below the header):
  - Left Sidebar
  - Main Content Area

## Top Navigation Bar
- Logo和平台名称
- 全局搜索框
- 快速创建按钮
- 通知中心图标
- 用户头像和设置入口

## Left Sidebar
- Dashboard导航
- Agent Management导航
- Model Management导航
- Orchestration Canvas导航
- Schedule Tasks导航(当前选中)
- Execution History导航
- Chat Interface导航
- 系统设置入口

## Main Content Area

### 页面标题与操作栏
- 页面标题"Schedule Tasks"
- 创建新任务按钮(主操作按钮)
- 批量操作按钮(批量启用/禁用/删除)
- 视图切换(列表视图/日历视图)

### 筛选与搜索栏
- 搜索框(按任务名称/目标搜索)
- 筛选条件:
  - 任务状态(全部/已启用/已禁用)
  - 任务类型(全部/编排流程/单个技能)
  - 执行频率(全部/每小时/每日/每周/每月/自定义)
  - 执行状态(全部/正常/失败/告警)
- 排序选项(下次执行时间/创建时间/成功率)

### 任务列表区域
- 任务卡片(多个):
  - 任务名称
  - 任务描述
  - 任务类型标签(编排/技能)
  - 目标显示:
    - 编排名称(如果是编排任务)
    - Agent名称+技能名称(如果是技能任务)
  - Cron表达式显示
  - 下次执行时间(倒计时)
  - 状态指示器(已启用/已禁用)
  - 执行统计:
    - 总执行次数
    - 成功率
    - 最近执行状态
  - 快速操作按钮:
    - 立即执行按钮
    - 启用/禁用切换
    - 编辑按钮
    - 更多操作菜单(查看日志/删除)
  - 创建时间

### 任务详情侧边抽屉(点击卡片展开)

#### 基本信息标签页
- 任务名称编辑
- 任务描述编辑
- 创建者和创建时间
- 最后修改时间
- 状态开关(启用/禁用)

#### 目标配置标签页
- 任务类型选择:
  - 执行编排流程(单选)
  - 执行Agent技能(单选)
- 目标选择(根据类型):
  - 编排流程选择下拉框(如选择"编排流程")
  - Agent选择下拉框 + 技能选择下拉框(如选择"Agent技能")
- 目标详情显示:
  - 选中的编排/Agent信息
  - 查看详情链接

#### 调度配置标签页
- Cron表达式编辑:
  - Cron表达式输入框
  - 可视化Cron编辑器(分钟/小时/日/月/周选择器)
  - 表达式验证和预览
  - 未来执行时间预览(显示接下来5次执行时间)
- 时区设置
- 快捷模板:
  - 每小时
  - 每天上午8点
  - 每周一上午9点
  - 每月1号上午10点
  - 自定义

#### 执行配置标签页
- 执行参数:
  - 参数列表(键值对输入)
  - 添加参数按钮
- 超时设置:
  - 执行超时时间(分钟)
- 重试策略:
  - 失败重试开关
  - 最大重试次数
  - 重试间隔(分钟)
- 并发控制:
  - 跳过执行(如果上次还在运行)
  - 排队等待
  - 强制终止上次并开始新的

#### 通知配置标签页
- 执行成功通知:
  - 通知开关
  - 通知方式(邮件/Webhook/站内消息)
  - 接收人列表
- 执行失败通知:
  - 通知开关
  - 通知方式
  - 接收人列表
- 性能告警:
  - 执行时长超过阈值告警
  - 成功率低于阈值告警

#### 执行历史标签页
- 历史记录列表:
  - 执行时间
  - 执行状态(成功/失败/超时)
  - 执行时长
  - 输出摘要
  - 错误信息(如果失败)
  - 查看详细日志按钮
- 分页控制
- 导出历史记录按钮

#### 统计分析标签页
- 执行统计卡片:
  - 总执行次数
  - 成功次数
  - 失败次数
  - 平均执行时长
  - 成功率
- 执行趋势图表:
  - 过去30天执行次数趋势
  - 成功率趋势
  - 执行时长趋势
- 失败原因分析:
  - 失败类型分布饼图
  - Top错误列表

### 底部操作按钮(详情抽屉内)
- 保存按钮
- 取消按钮
- 立即执行按钮
- 删除任务按钮
