# Agent Management
智能体角色管理中心,提供角色创建、配置、测试和版本管理能力,支持能力模块化定义和跨项目复用。

Layout Hierarchy:
- Header (Full-width):
  - Top Navigation Bar
- Content Container (Positioned below the header):
  - Left Sidebar
  - Main Content Area

## Top Navigation Bar
- Logo和平台名称
- 全局搜索框
- 快速创建按钮
- 通知中心图标
- 用户头像和设置入口

## Left Sidebar
- Dashboard导航
- Agent Management导航(当前选中)
- Model Management导航
- Orchestration Canvas导航
- Schedule Tasks导航
- Execution History导航
- Chat Interface导航
- 系统设置入口

## Main Content Area

### 页面标题与操作栏
- 页面标题"Agent Management"
- 创建新Agent按钮(主操作按钮)
- 批量操作按钮(导入/导出/删除)
- 视图切换(列表视图/卡片视图)

### 筛选与搜索栏
- 搜索框(按名称/标签/技能搜索)
- 筛选条件:
  - 角色状态(全部/已激活/草稿/已归档)
  - 模型类型(全部/OpenAI/Claude/本地模型)
  - 标签筛选(下拉多选)
  - 创建者筛选
- 排序选项(创建时间/最近使用/名称)

### Agent列表区域
- Agent角色卡片(多个):
  - 角色名称
  - 角色图标/头像
  - 简要描述
  - 绑定的模型标签
  - 技能数量标识
  - 使用频率统计
  - 状态标签(激活/草稿/归档)
  - 快速操作按钮:
    - 编辑按钮
    - 测试按钮
    - 复制按钮
    - 更多操作菜单(删除/归档/导出)
  - 最后修改时间

### Agent详情侧边抽屉(点击卡片展开)

#### 基本信息标签页
- 角色名称和头像
- 角色描述(富文本)
- 创建者和创建时间
- 标签列表
- 版本号和版本历史链接

#### 技能配置标签页
- 技能集列表:
  - 技能名称
  - 技能描述
  - 技能类型(对话/分析/生成/执行)
  - 添加/删除技能按钮
- 提示词编辑器:
  - System Prompt编辑区域
  - Few-shot示例管理
  - 提示词变量定义
  - 测试提示词按钮

#### 模型绑定标签页
- 当前绑定的模型信息:
  - 模型名称和版本
  - 模型提供商
  - 更换模型按钮
- 模型参数配置:
  - Temperature滑块
  - Max Tokens输入框
  - Top P滑块
  - Frequency Penalty滑块
  - Presence Penalty滑块
  - Stop Sequences输入

#### 工具权限标签页
- MCP工具绑定:
  - 可用MCP服务器列表
  - 已绑定工具列表(工具名称、描述、权限级别)
  - 添加工具按钮
- 命令权限配置:
  - 允许执行的命令列表
  - 命令权限级别(只读/读写/管理员)
  - 命令白名单/黑名单设置
- API权限配置:
  - 可调用的API端点列表
  - API调用频率限制
  - API密钥管理

#### 知识库关联标签页
- 已关联的知识库列表:
  - 知识库名称
  - 知识库类型(文档库/向量库/图谱)
  - 检索策略(语义检索/关键词/混合)
  - 移除关联按钮
- 添加知识库按钮
- 知识库检索配置:
  - Top K设置
  - 相似度阈值
  - 重排序策略

#### 记忆管理标签页
- 记忆策略配置:
  - 上下文记忆窗口大小(轮数)
  - 长期记忆存储开关
  - 记忆压缩策略(摘要/向量化)
  - 记忆检索优先级
- 当前记忆查看:
  - 短期记忆列表(最近对话)
  - 长期记忆摘要
  - 清除记忆按钮
- 记忆检索测试:
  - 输入查询关键词
  - 查看检索到的记忆片段

#### 性能监控标签页
- 调用统计:
  - 总调用次数
  - 平均响应时间
  - 成功率
  - Token消耗统计
- 性能趋势图表:
  - 过去7天调用量趋势
  - 响应时间趋势
  - 错误率趋势
- 最近执行日志:
  - 执行时间
  - 输入输出摘要
  - 执行状态
  - 查看详情链接

### 底部操作按钮(详情抽屉内)
- 保存修改按钮
- 取消按钮
- 测试Agent按钮
- 查看使用记录按钮
