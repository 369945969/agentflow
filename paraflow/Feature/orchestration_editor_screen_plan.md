# Orchestration Editor
可视化智能体编排编辑器,提供拖拽式画布操作、节点连线、流程配置和实时验证能力,支持复杂拓扑结构设计。

Layout Hierarchy:
- Header (Full-width):
  - Editor Top Bar
- Content Container (Positioned below the header):
  - Left Toolbox Panel
  - Center Canvas Area
  - Right Properties Panel

## Editor Top Bar
- 返回编排列表按钮
- 编排名称显示与编辑
- 保存状态指示器(已保存/未保存)
- 操作按钮组:
  - 保存按钮
  - 另存为按钮
  - 试运行按钮
  - 正式执行按钮
  - 版本历史按钮
  - 分享与协作按钮
- 用户头像

## Left Toolbox Panel

### Agent角色库区域
- 搜索框(按名称/标签筛选)
- 角色分类标签(全部/自定义/系统内置)
- Agent角色卡片列表:
  - 角色名称
  - 角色图标
  - 简要描述
  - 拖拽手柄

### 控制节点库区域
- 条件分支节点
- 并行执行节点
- 循环节点
- 延迟节点
- 数据转换节点

### 画布操作工具
- 选择工具(默认)
- 连线工具
- 框选工具
- 缩放控制(放大/缩小/适应窗口)
- 网格显示开关
- 对齐辅助线开关

## Center Canvas Area

### 画布工具栏
- 当前缩放比例显示
- 画布重置按钮
- 自动布局按钮
- 显示执行路径按钮
- 流程验证状态指示(通过/有错误)

### 可视化编排画布
- 无限画布(支持拖拽移动)
- 网格背景
- 智能体节点:
  - 节点名称
  - 节点类型图标
  - 输入/输出连接点
  - 状态指示器(配置完整/缺少配置)
  - 选中高亮效果
- 连接线:
  - 数据流向箭头
  - 连接类型标注(顺序/条件/循环)
  - 悬停显示数据映射信息
- 起始节点和结束节点

### 画布右键菜单
- 复制节点
- 删除节点
- 编辑节点属性
- 查看节点文档
- 添加注释

## Right Properties Panel

### 节点配置区域(当选中节点时)
- 节点基本信息:
  - 节点ID
  - 节点名称编辑
  - 节点描述编辑
- Agent配置:
  - 选择的Agent角色
  - 更换角色按钮
  - 查看角色详情链接
- 输入配置:
  - 输入参数列表
  - 数据源选择(上游节点输出/固定值)
  - 数据映射编辑器
- 执行配置:
  - 超时时间设置
  - 重试策略(重试次数/间隔)
  - 失败处理(继续/终止流程)
- 输出配置:
  - 输出参数定义
  - 输出转换规则

### 流程全局配置区域(当未选中节点时)
- 编排元信息:
  - 编排名称
  - 编排描述
  - 创建者和创建时间
  - 标签管理
- 全局变量:
  - 变量名称
  - 变量类型
  - 默认值
  - 添加/删除变量按钮
- 触发配置:
  - 手动触发
  - 定时触发设置
  - Webhook触发URL
  - 事件触发配置
- 通知配置:
  - 成功通知(邮件/Webhook)
  - 失败通知
  - 通知接收人

### 验证与错误提示区域
- 实时验证结果
- 错误列表(节点缺少配置/连接不完整/循环依赖)
- 警告列表(性能建议/最佳实践提示)
- 跳转到错误节点按钮
