# Execution Monitor
实时执行监控与追踪页面,提供可视化执行图谱、详细日志、性能分析和调试能力,支持暂停、回溯和问题定位。

Layout Hierarchy:
- Header (Full-width):
  - Monitor Top Bar
- Content Container (Positioned below the header):
  - Center Execution Graph Area
  - Right Details Panel
  - Bottom Log Panel (可折叠)

## Monitor Top Bar
- 返回按钮(返回执行历史或编排编辑器)
- 执行任务信息:
  - 编排名称
  - 执行ID
  - 触发方式标签(手动/定时/Webhook)
  - 开始时间
- 整体执行状态:
  - 状态标识(运行中/已完成/失败/已暂停)
  - 进度百分比
  - 已执行节点/总节点数
- 执行控制按钮:
  - 暂停按钮(运行中时)
  - 继续按钮(暂停时)
  - 停止按钮
  - 重新执行按钮
  - 导出执行报告按钮
- 视图控制:
  - 自动居中当前节点开关
  - 显示数据流动画开关
  - 全屏模式切换
- 用户头像

## Center Execution Graph Area

### 图谱工具栏
- 缩放控制(放大/缩小/适应窗口)
- 布局方向切换(横向/纵向)
- 图例显示开关
- 性能热力图开关(节点按耗时着色)
- 错误路径高亮按钮

### 可视化执行图谱
- 流程节点:
  - 节点名称
  - 节点状态图标:
    - 等待中(灰色)
    - 运行中(蓝色动画)
    - 已完成(绿色)
    - 失败(红色)
    - 跳过(黄色)
  - 执行耗时标注
  - 节点边框颜色表示状态
  - 选中节点高亮效果
- 连接线与数据流:
  - 已执行路径高亮(粗线)
  - 未执行路径灰化(细线)
  - 数据流动动画(运行中时)
  - 数据传输量标注
- 当前执行节点:
  - 特殊高亮效果(呼吸动画)
  - 自动居中显示
- 错误节点标识:
  - 红色边框和错误图标
  - 错误类型标注

### 图例说明
- 节点状态说明
- 连接线类型说明
- 颜色编码含义

## Right Details Panel

### 选中节点详情(点击节点时)

#### 节点执行信息
- 节点名称和类型
- Agent角色信息
- 执行状态
- 开始时间和结束时间
- 执行耗时
- 重试次数(如有)

#### 输入数据区域
- 输入参数列表:
  - 参数名称
  - 参数值(支持折叠/展开)
  - 数据来源标注(上游节点/固定值)
- 数据格式化显示(JSON/表格/文本)
- 复制输入数据按钮

#### 输出数据区域
- 输出结果展示:
  - 输出参数列表
  - 参数值(支持折叠/展开)
  - 数据格式化显示
- 复制输出数据按钮
- 下载输出数据按钮

#### 执行日志区域
- 节点专属日志:
  - 时间戳
  - 日志级别(INFO/WARN/ERROR)
  - 日志内容
  - 日志搜索框
- 过滤条件(按级别筛选)
- 展开到底部日志面板按钮

#### 性能分析
- Token消耗统计
- API调用次数
- 内存使用情况
- 与历史平均值对比

#### 错误信息(如节点失败)
- 错误类型
- 错误消息
- 错误堆栈
- 建议的修复方案
- 重试此节点按钮

### 整体执行摘要(未选中节点时)

#### 执行元信息
- 编排名称和版本
- 执行ID
- 触发者
- 触发方式和触发时间
- 执行环境信息

#### 整体性能指标
- 总执行时长
- 各节点耗时分布图表
- 总Token消耗
- API调用总次数
- 资源使用峰值

#### 执行统计
- 总节点数
- 成功节点数
- 失败节点数
- 跳过节点数
- 成功率百分比

#### 关键路径分析
- 最耗时的节点列表(Top 5)
- 关键路径标识
- 优化建议

## Bottom Log Panel

### 日志面板标题栏
- "Execution Logs"标题
- 折叠/展开按钮
- 日志级别筛选(All/INFO/WARN/ERROR)
- 搜索框(关键词搜索)
- 清空显示按钮
- 下载日志按钮

### 日志列表区域
- 实时日志流:
  - 时间戳
  - 日志级别图标和颜色
  - 来源节点标识(点击跳转到节点)
  - 日志内容
  - 展开详细信息按钮(如有堆栈)
- 自动滚动到最新日志开关
- 虚拟滚动支持大量日志

### 日志统计信息
- 日志总数
- 错误日志数
- 警告日志数
