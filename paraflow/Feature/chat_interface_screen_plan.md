# Chat Interface
协作聊天界面,支持与多个智能体角色对话、绑定编排流程、查看对话历史和角色记忆。

Layout Hierarchy:
- Header (Full-width):
  - Top Navigation Bar
- Content Container (Positioned below the header):
  - Left Sidebar (两层结构)
    - 平台导航栏(上层)
    - 会话列表栏(下层)
  - Main Chat Area
  - Right Context Panel(可折叠)

## Top Navigation Bar
- Logo和平台名称
- 全局搜索框
- 快速创建按钮
- 通知中心图标
- 用户头像和设置入口

## Left Sidebar

### 平台导航栏(上层,窄条)
- Dashboard导航
- Agent Management导航
- Model Management导航
- Orchestration Canvas导航
- Schedule Tasks导航
- Execution History导航
- Chat Interface导航(当前选中)
- 系统设置入口

### 会话列表栏(下层,宽条)
- 会话列表标题"Conversations"
- 新建会话按钮(主操作按钮)
- 搜索框(搜索会话)
- 会话卡片列表(多个):
  - 会话名称
  - 参与的Agent头像列表(最多显示3个)
  - 最后一条消息摘要
  - 最后活动时间
  - 选中高亮效果
- 会话右键菜单:
  - 重命名会话
  - 删除会话
  - 导出会话

## Main Chat Area

### 聊天工具栏
- 当前会话名称(可编辑)
- 参与的Agent标签列表:
  - Agent名称和头像
  - 移除Agent按钮(X)
- 添加Agent按钮(+)
- 绑定编排按钮:
  - 当前绑定的编排名称(如有)
  - 更换/解绑按钮
- 清空对话按钮
- 更多操作菜单(导出对话/会话设置)

### 消息展示区域
- 消息列表(滚动):
  - 系统消息(会话开始/Agent加入/编排绑定等):
    - 消息内容
    - 时间戳
  - 用户消息:
    - 用户头像
    - 消息内容
    - 时间戳
  - Agent回复消息:
    - Agent头像和名称
    - 消息内容(支持Markdown渲染)
    - 时间戳
    - 反馈按钮(👍/👎)
    - 复制按钮
    - 查看推理过程按钮(展开显示Agent的思考步骤)
  - 编排执行消息:
    - 编排名称
    - 执行状态(运行中/已完成/失败)
    - 执行摘要
    - 查看详细执行图谱按钮
  - 正在输入指示器(Agent正在思考时)

### 消息输入区域
- 多行文本输入框(支持Markdown)
- 输入工具栏:
  - 格式化按钮(粗体/斜体/代码)
  - 附件上传按钮
  - @提及Agent按钮(指定特定Agent回复)
  - 触发编排按钮(选择绑定的编排执行)
- 发送按钮
- 快捷键提示(Shift+Enter换行,Enter发送)

## Right Context Panel

### 面板标题栏
- "Context & Memory"标题
- 折叠/展开按钮
- 标签页切换:
  - 参与者
  - 对话记忆
  - 编排配置

### 参与者标签页
- 参与的Agent列表:
  - Agent卡片(多个):
    - Agent头像和名称
    - 角色描述
    - 绑定的模型
    - 当前状态(活跃/空闲)
    - 查看详情按钮
    - 移除按钮
- 添加Agent按钮(从Agent库选择)
- Agent选择弹窗:
  - Agent列表(卡片)
  - 搜索和筛选
  - 批量添加

### 对话记忆标签页
- 上下文记忆:
  - 当前对话轮数
  - 记忆窗口大小设置
  - 最近记忆摘要
- 关键信息提取:
  - 自动提取的关键实体列表
  - 自动提取的重要决策列表
- Agent个人记忆(按Agent分组):
  - Agent名称
  - 该Agent的记忆片段列表
  - 查看完整记忆按钮
- 清除记忆按钮

### 编排配置标签页
- 当前绑定的编排:
  - 编排名称和描述
  - 编排预览图(简化的流程图)
  - 查看完整编排按钮
  - 解绑按钮
- 绑定新编排按钮
- 编排选择弹窗:
  - 编排列表(卡片)
  - 搜索和筛选
  - 预览编排流程
  - 选择并绑定按钮
- 执行配置:
  - 触发方式(手动/自动)
  - 触发条件(关键词/特定场景)
  - 执行参数映射

### 会话设置区域
- 会话名称编辑
- 会话描述编辑
- 自动保存开关
- 记忆策略选择:
  - 全量保存
  - 智能摘要
  - 仅保留关键信息
